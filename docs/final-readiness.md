## Honest status
On 13 November 2026 the development environment ran the full Maven build with all JUnit suites (101 tests, with the JDBC tests against MySQL 8.4.6), every console demo, and the WAR on Payara Server 6.2025.10 (91/91 HTTP checks with both the bash and the PowerShell 7 script; an earlier Payara Micro run passed the then 64 checks). The Android app was built with the Gradle wrapper (`assembleDebug testDebugUnitTest`: BUILD SUCCESSFUL, 47 JVM unit and Robolectric tests passed, 0 failures; the optional `LiveServerTest` also passed against the deployed server, see `docs/evidence/android-live-server-check.txt`). **No Android emulator or device was run in the development environment**; the emulator scenarios and screenshots are for the group. See `docs/testing/LOCAL_SMOKE_TEST_RESULTS.md`. The group must repeat these steps on their own laptop and take screenshots using `docs/testing/SCREENSHOT_TEST_GUIDE.md`. The emulator runs, real campus coordinates, the usability sessions, the contribution log and Git tags are still open.
