# SCASP User Guide

## Student
1. Open the SCASP web or mobile client.
2. Sign in using the student demonstration account.
3. Open Course Catalogue to view available courses.
4. Select a course and submit registration.
5. If the course is full, the system places the student on its waiting list.
6. Use Withdraw to leave a course. If a place becomes available, the next waiting student is promoted.
7. Open Service Requests, select a category, enter a description and submit.
8. Read announcements on the dashboard.
9. Open Campus Services to view configured locations.

## Staff
1. Sign in using a staff account.
2. Open the staff dashboard.
3. Review service requests by priority and status.
4. Assign requests to a staff member and update their status.
5. Manage course details and capacity.
6. Publish announcements for a defined audience.
7. Review registration, waiting-list and workload reports.

## Error handling
Check that required fields are completed. If a service is unavailable, retry later or contact the system administrator. Never share passwords.
